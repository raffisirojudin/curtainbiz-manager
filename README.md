## 📌 Tentang CurtainBiz Manager
CurtainBiz Manager adalah sistem informasi manajemen internal (POS & Mini-ERP) yang dirancang khusus untuk pelaku bisnis gorden atau tirai jendela. Aplikasi ini menyelesaikan masalah rumitnya menghitung estimasi biaya gorden yang biasanya bergantung pada panjang kain, lipatan, dan jenis rel.

### ✨ Fitur Utama
* **Automated Pricing Calculator:** Input ukuran jendela (tinggi x lebar), pilih jenis kain, dan sistem akan otomatis menghitung kebutuhan yard/meter beserta harganya.
* **Order Tracking:** Mengelola status pesanan pelanggan mulai dari tahap *survey*, penjahitan, hingga pemasangan di lokasi.
* **Inventory Management:** Pemantauan stok gulungan kain gorden dan aksesori pendukung secara *real-time*.
* **Invoice Generator:** Membuat nota tagihan digital siap cetak untuk pelanggan.

### 🛠️ Tech Stack
* **Core:** HTML5, CSS3, JavaScript (ECommerce/Billing logic), LocalStorage untuk manajemen data inventaris lokal.
